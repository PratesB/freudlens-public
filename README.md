## 🔒 Privacy-First Architecture (BYOK)

FreudLens is built with absolute respect for user privacy. 
- **Bring Your Own Key (BYOK):** The application requires users to input their own AI API key to generate the analysis.
- **Zero Data Retention:** API keys and personal answers are processed strictly ephemerally. They are never stored in any database or logged on our servers. You can inspect the open-source code to verify this architecture.

## 🛠️ Technology Stack

This repository is structured as a monorepo containing both the frontend and backend applications.

**Frontend:**
- Vue 3
- Vite (Build Tool)
- Vue Router (Navigation)
- Tailwind CSS (Styling)

**Backend:**
- Python 3.10+
- Django (Web Framework)
- Django Ninja (Fast, async-ready REST API)
- Google GenAI (`google-genai` for Gemini API integration)
- Pydantic (Data validation)
- python-decouple (Environment variables management)
- Uvicorn (ASGI server)
- SQLite (for storing the static questionnaire data)
- Docker & Docker Compose

## 🚀 Getting Started (Local Development)

To run this project locally on your machine, you'll need to set up both the backend API and the frontend client.

### Prerequisites
- Python 3.10+
- Node.js 18+
- Docker (Optional, but recommended for the backend)

### 1. Running the Full Stack with Docker (Recommended)

The easiest way to run the entire project (Frontend + Backend) is using Docker Compose from the root directory. The backend serves the questionnaire data and acts as a secure bridge for the AI integration, while the frontend provides the interactive interface.

```bash
# Ensure you are in the root directory
# Create environment files for both backend and frontend
cp backend/.env.example backend/.env
cp frontend/.env.example frontend/.env

# Build and start both services
docker-compose up --build
```
Once it finishes, both servers will be up:
- Frontend: `http://localhost:5173`
- Backend API: `http://localhost:8000`

### 2. Manual Setup (Without Docker)

If you prefer to run the services manually, you need to set up both environments separately.

#### Backend Manual Setup

```bash
# Navigate to the backend directory
cd backend

# Create a virtual environment and activate it
python -m venv venv
source venv/bin/activate  # On Windows use: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Run migrations and load the initial database data
python manage.py migrate
python manage.py loaddata questions.json

# Start the development server
python manage.py runserver
```
The API will be available at `http://localhost:8000`.

#### Frontend Manual Setup

The frontend provides the interactive interface and handles the BYOK logic.

```bash
# Navigate to the frontend directory
cd frontend

# Create a copy of the environment variables file
cp .env.example .env

# Install dependencies
npm install

# Start the development server
npm run dev
```
The web app will be available at `http://localhost:5173`.
